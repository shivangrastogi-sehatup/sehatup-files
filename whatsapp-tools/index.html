🔗 Enable saving edits back to the sheet

  1. Open your Google Sheet → Extensions ▸ Apps Script.
  2. Delete any code, paste the script below, click Save 💾.
  3. Click Deploy ▸ New deployment → type Web app.
  4. Set Execute as: Me, Who has access: Anyone → Deploy → authorize.
  5. Copy the Web app URL and paste it into Settings ▸ Save endpoint.
